# Gameplay modules

This folder contains optional gameplay features loaded by `accra-life.js` after the core life system is ready.

- `accra-crime.js` — wanted levels, police patrols and arrests
- `accra-pub.js` — Accra Vibes Pub activities and interactions
- `accra-mining.js` — quarry and gold-works mining gameplay
- `accra-fx.js` — gameplay effects, sounds, emotes and sector culling
- `accra-carskin.js` — disabled custom vehicle skin switch; built-in vehicle remains active

These modules are dynamically loaded, so keep their paths in `accra-life.js` synchronized.
