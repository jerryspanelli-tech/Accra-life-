# Accra Life (Babylon.js 3D Game)

**Accra Life** is an open-world 3D simulation game built with **Babylon.js** and hosted on **GitHub Pages**. Explore the vibrant city of Accra, Ghana, navigate real-world districts, visit landmarks, drive vehicles, and experience dynamic weather!

## 🌍 Features
- **Detailed Map & Districts**: Makola Market, Osu, East Legon, Labadi Beach, Accra Mall, and more.
- **Transportation**: Kumasi-to-Accra highway connection and Ayalolo bus routes.
- **Dynamic Weather**: Automatic atmospheric changes and rain systems.
- **Multiplayer & Customization**: Character creation, avatar styles, and Supabase backend integration.

## 🚀 Built With
- **Babylon.js** (3D Engine & Physics)
- **Supabase** (Multiplayer backend)
- **GitHub Pages** (Hosting)
