# World and regional environment

This folder contains the code that builds and describes the game world.

- `region/accra-world.js` — large-world map and streamed world sections
- `region/accra-districts.js` — Accra district layouts and architecture
- `region/accra-towns.js` — towns along the Accra–Kumasi route
- `region/landmarks.js` — Labadi Beach and coastal landmarks
- `region/accra-weather.js` — weather and atmospheric conditions
- `transport/` — roads, airports, traffic, tolls and public transport

Keep script references in the production page, archived page and test pages aligned with these locations.
