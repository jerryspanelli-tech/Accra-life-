# Building and interior systems

This folder contains code for structures, civic facilities, estates, shops and walkable building interiors.

- `accra-apartments.js` — apartment rental and tenancy system
- `accra-estate.js` — Amoamah Estate environment
- `accra-market.js` — Makola market stalls
- `accra-mall.js` — Accra Galleria exterior
- `accra-hq.js` and `accra-hospital.js` — police HQ and hospital exteriors
- `accra-civic-models.js` — detailed civic building and emergency-vehicle models
- `accra-interiors.js` and `accra-entries.js` — interior rooms and building entry/exit
- `accra-decor.js` — home interior decoration tiers

The production page loads the building modules directly; `accra-life.js` loads the home decoration module dynamically.
