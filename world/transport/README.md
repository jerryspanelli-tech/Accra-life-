# Transport and road systems

This folder contains the modules responsible for roads, traffic control, toll infrastructure, highways, airports, NPC traffic, public transport and Shaxi/taxi rides.

- `accra-roads.js` — city junction signals and pedestrian crossings
- `accra-toll.js` — toll plaza construction
- `accra-highway.js` — highway lighting
- `accra-airport.js` — Kotoka airport environment
- `accra-kumasi-airport.js` — Kumasi airport environment
- `accra-traffic.js` — moving NPC road traffic
- `accra-transport.js` — trotros and bus routes
- `accra-shaxi.js` — Shaxi and taxi ride service

The production page loads these modules from this directory. Keep asset URLs and script references synchronized when changing paths.
