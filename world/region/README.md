# Regional world modules

- accra-world.js — large-world map and streamed world sections
- accra-districts.js — Accra district layouts and architecture
- accra-towns.js — towns along the Accra–Kumasi route
- landmarks.js — Labadi Beach and coastal landmarks
- accra-weather.js — weather and atmospheric conditions

The production page loads district, town and landmark modules directly. The world and weather modules are dynamically loaded by accra-life.js.
