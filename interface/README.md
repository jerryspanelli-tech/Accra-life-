# In-game interface

This folder contains the player's in-game interface and presentation controls.

- `phone.js` — smartphone apps and phone interface
- `accra-phone-skin.js` — visual styling for the in-game phone
- `accra-camera.js` — third-person follow camera rig
- `accra-settings.js` — camera, graphics, lighting, fog and audio settings

The production and archived game pages load these scripts directly from this folder.
